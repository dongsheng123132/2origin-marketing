# 2origin-marketing · AI 计算机营销素材中心

> 营销素材的**唯一真相源**（比网站可靠——网站会没，GitHub 在）。
> 所有素材产出即入仓，第一时间可发布。更新快 = git push 即同步。

## 为什么放 GitHub

- **可靠**：网站可能没，GitHub 在
- **SEO**：GitHub 页面被 Google 收录，素材本身就是引流入口
- **快**：素材产出 → commit → push → 可发布，不用等网站部署
- **版本化**：每次改动能回溯

## 目录

```text
marketing-points/   营销点库（每个项目可讲的故事 + 数据背书）
drafts/             草稿文章（待审 → 过审后发布）
campaigns/          发布台文案（bomber 多平台发）
kicker/             金句库（标题/引言直接用）
```

## 工作流（更新快）

1. 素材产出 → 写进对应目录
2. `git add -A && git commit && git push` → 立即同步
3. 博客/发布台需要时，从仓库取最新版发布

## 铁律

- **草稿制**：`drafts/` 里的文章发布前须用户审
- **诚实边界**：营销点必须真实可核验，不宣称未实现能力
- **脱敏**：涉他人资料的内容脱敏再发
- **CTA 一律引 U-King**：`https://u-claw.org.cn/download/U-King-Setup.exe`

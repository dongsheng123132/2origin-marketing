<h1>5 分钟跑通一台 AI 计算机（零依赖）</h1>

<p>2origin-harness 是 2Origin 架构的参考实现。今天补上了英文 QUICKSTART——目标很简单：让人在 5 分钟内跑通一遍，而不是读完一篇架构长文然后关掉。</p>

<p>前置条件只有一条：<strong>Node ≥ 18</strong>。没有任何依赖需要装。</p>

<pre><code>git clone https://github.com/dongsheng123132/2origin-harness
cd 2origin-harness</code></pre>

<h2>七条命令，跑完就是一台 v0.2 机器</h2>

<p><strong>1. 建状态</strong>——注意建的是「状态」，不是聊天记录。</p>

<pre><code>node bin/2origin.mjs init --id demo-quick --goal "write a launch doc"</code></pre>

<p>任务落在一个 <code>task.origin.json</code> 里。会话没了，它还在。</p>

<p><strong>2. 记一条已验证事实</strong>——来源必须可核验。</p>

<p>事实的 <code>source</code> 只接受文件路径、命令、或测试用例 ID。你写「相信我」，它会直接抛错。这条规则听起来苛刻，但它是「AI 记忆」和「AI 幻觉」之间唯一的分界线。</p>

<p><strong>3. 通过南桥写文件</strong>——写操作全程审计。</p>

<pre><code>node bin/2origin.mjs write --relpath demo/demo-quick/launch.md --content "# Launch v0.1"
# { status: "done", evidence: { exists: true, size_bytes: 14 } }</code></pre>

<p>关键在于：这个 <code>status</code> 不是写入调用自己说的，是<strong>写完之后回头看磁盘</strong>确认的。路径穿越会被拒，写入范围有白名单。</p>

<p><strong>4. 编译本境 bundle</strong>——会话启动时注入的就是这个。</p>

<pre><code>node bin/2origin.mjs bundle
# 装载 1/1 份学历 · 已验证事实 1/1 条
# ✔ 无丢弃</code></pre>

<p>预算有限时它会丢东西，但它<strong>会告诉你丢了什么</strong>。没有静默丢失。</p>

<p><strong>5. 用观察现实来验证</strong>，而不是相信声称。</p>

<pre><code>node bin/2origin.mjs verify --state demo/demo-quick/task.origin.json
# ✅ VERIFIED</code></pre>

<p>它检查两件事：声称的产物在磁盘上真的存在吗？已验证事实的来源真的可核验吗？上线第一天，这条就抓出过一个真实的「幽灵产物」bug——AI 说它写了文件，其实没有。</p>

<p><strong>6. 沉淀经验</strong>——candidate 起步，不自动转正。</p>

<p>新学到的东西一律标 <code>candidate</code>，只有显式晋升才变成 <code>verified</code>。一次成功不等于永久真理，这是刻意做的减速带。</p>

<p><strong>7. 乐观锁</strong>——两个写入者不会互相覆盖。</p>

<p>带上过期的哈希去写，它拒绝执行。第二个人记的事实不会被悄悄吃掉。</p>

<h2>跑完之后</h2>

<p>七条命令，你手上就是一台 2Origin v0.2 机器：模型可换、状态不丢、写操作可审计、经验会复利。零依赖。</p>

<p>想确认它不是花架子，再跑一条：</p>

<pre><code>npm test
# tests 34 · pass 34 · fail 0</code></pre>

<p>（一个小提醒：这套测试和架构仓库的 conformance 脚本共享部分状态目录，两个同时跑会互相干扰、报假失败。一次跑一个。）</p>
